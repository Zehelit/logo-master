# Logo Master

Logo keşfi, gerçek fontlarla tipografi, vektör ve Canva üretimi için kişisel Codex skill paketi. Referans belgelerini, Python yardımcılarını ve mevcut testlerini içerir.

## İçerik

Skill paketi `skills/logo-master/` altındadır. Ana yönerge `skills/logo-master/SKILL.md` dosyasıdır.

## Yerel kullanım

`skills/logo-master` klasörünü Codex kullanıcı skill dizinine (`~/.codex/skills/logo-master`) kopyalayın. Skill içindeki araç ve platform gereksinimlerini kullanmadan önce inceleyin.

Bu depo mevcut yerel skill dosyalarının kaynak kopyasını içerir. Python önbellekleri pakete dahil edilmez.
